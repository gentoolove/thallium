# Security Policy

## Supported Versions

All versions of this project are currently being supported with security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| All     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public issue**. 

Instead, report it safely by following these steps:
1. Send a detailed description of the vulnerability to: **gentoolove@proton.me**
2. Include steps to reproduce the issue, potential impact, and any relevant logs or system details.

We take security issues seriously and will respond to your report as quickly as possible to coordinate a fix. Thank you for helping keep this project secure!
